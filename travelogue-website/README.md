# Palakkad Travelogue Website

A bespoke, responsive static travelogue website dedicated to **Palakkad District, Kerala** ("The Gateway to Kerala"). Built with authentic high-resolution local photography, zero dependencies, no build step, pure HTML5, CSS3, and modern vanilla JavaScript.

---

## 🚀 How to Run It

1. Simply double-click `index.html` or open it in any modern browser.
2. All images are packaged locally inside the `images/` folder, allowing it to load offline seamlessly.

```

├── style.css        # Responsive styling, photo cards, zoom hover effects, dialog overlays
├── script.js        # 12 destination objects with photos, 5 field journals, trip calculator
├── README.md        # Documentation and guides
```
